# Formatted

Main application for CSV normalization, SQL lessons, quizzes and timed practice.

- `app`: pages, components, services, stores, types and styles.
- `electron`: desktop entry point, IPC and Calc/Ollama integration.
- `desktop-tools`: Python helpers used by the Calc lesson.
- `tests`: application and Calc checks.

Run `npm run check` and `npm run test:ui` from the repository root. The build keeps
the existing `forma://app/index.html` address and application profile.
